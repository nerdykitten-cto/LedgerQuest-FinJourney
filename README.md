# FinJourney

Personal finance RPG powered by Google Antigravity. Transform financial habits into an epic story-driven campaign.

## Project Overview
FinJourney bridges the gap between tedious expense tracking and engaging RPG gameplay. By using **Google Antigravity**, the game dynamically generates quests, adjusts difficulty, and crafts a unique narrative based on your real-life financial behavior.

### Core Loop
1. **Finance Side:** Track expenses, set budgets, and achieve savings goals.
2. **Action Point (AP) Engine:** Daily financial "wins" accumulate as Action Points.
3. **Game Side:** Spend AP in the evening to advance your party through a story-driven RPG campaign.
4. **Agentic Logic:** Antigravity observes your progress, infers your skill/retention risk, and decides the next quest's challenge and rewards.
